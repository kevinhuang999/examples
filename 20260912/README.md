# 示例：仪器导出的检验数据批量生成 PDF 检验报告

一个样品一份 PDF，按 `样品编号` 自动归堆、自动分页、表头每页重复。
配套文章讲的是报告里那三个绕不开的坑：中文字体、跨页表头、单元格里的 `&`。

## 目录结构

```
20260912/
├── README.md                  ← 你正在看的这份，先看它
├── run.py                     ← 一键脚本，跑主线（你要碰的就这一个）
├── 01_raw_data/
│   └── 检验结果_仪器导出.csv    ← 仪器工作站导出的原始明细（01 → 02 就是操作顺序）
├── 02_output/                 ← 跑完出来的 PDF，脚本自动建、自动清
└── source/
    ├── build_fixtures.py      ← 重新造上面那份 CSV
    ├── run_log.txt            ← 运行日志，每次追加一段
    └── requirements.txt
```

你只需要碰两处：把仪器导出的 CSV 换掉、跑 `run.py`。其余是脚手架。

## 怎么跑

```bash
python run.py
```

- 缺 reportlab / pypdf 会自动用清华源装，装不上退 `--user`。
- Windows 上双击 `run.py` 也能跑，跑完停在窗口等你按回车。
- 不想暂停（放脚本里跑）：`python run.py --no-pause`
- 手动装依赖：`pip install -i https://pypi.tuna.tsinghua.edu.cn/simple reportlab pypdf`

重造原始数据（CSV 被改乱了想还原）：

```bash
python source/build_fixtures.py
```

## 数据故意造了哪些边界

| 边界 | 在哪 | 想验证什么 |
| --- | --- | --- |
| 检验结果为空 | 001 的「干燥失重」 | 空格子不能渲染成 `None`，也不能让整行塌掉 |
| 批号 `00903` | 001 | 全程按文本读，前导零不能丢 |
| 样品编号带斜杠 `S/2026/0912/003` | 003 | 直接拿编号当文件名会写不出去，得先换掉非法字符 |
| 检项 34 条 | 004 | 一页装不下要跨页，第二页的表头必须重复 |
| 检项 1 条 / 2 条 | 003 / 002 | 极少条数不能报错，页数得是 1 |
| 文字里带 `&` | 002 的样品名称（水系统取样点写法） | 会被 reportlab 的迷你 HTML 改动（见下） |
| 空行 + 表尾「合计」行 + 说明行 | CSV 末尾三行 | 不能被当成样品，生成出 `检验报告_合计.pdf` |

## 实测发现的问题与改法

1. **表尾「合计」行被当成一个样品。** 仪器导出的合计行里，条数会落到「检验项目」那一列。
   第一版只判「样品编号和检验项目都非空」，结果多出一份 `检验报告_合计.pdf`（4 份变 5 份，回读校验 FAIL）。
   改法：再加一道「检测日期非空」兜底——真数据行一定有检测日期。
2. **不注册中文字体会出方块。** 默认字体 Helvetica 没有汉字，整页汉字渲染成 `■`，不报错、不提示。
   改法：启动时按候选列表注册一个系统中文字体（Windows 用 `msyh.ttc`，macOS 用 PingFang，Linux 用 Noto/文泉驿）。
3. **跨页后第二页没有表头。** `Table` 不设 `repeatRows=1` 时，第二页光秃秃全是数据行，读者不知道哪列是哪列。
   改法：`repeatRows=1`，实测第二页五个列头都在。
4. **单元格里的 `&` 被悄悄改字。** `Paragraph` 吃的是迷你 HTML，`A&B` 输出成 `A&B;`（多一个分号）；
   `<b>` 这类会被当成标签吃掉。都不报错，就是数据悄悄变了。
   改法：进 `Paragraph` 之前统一 `escape()`。
5. **编号里的斜杠。** 拿 `S/2026/0912/003` 直接当文件名，Windows 上写不出文件。
   改法：`re.sub(r'[\\/:*?"<>|]', "_", ...)` 换成下划线。

## 验证环境与已知限制

- 实测环境：Windows + Python 3.13 + reportlab 5.0.0 + pypdf；4 份 PDF、8 项回读校验全绿 PASS。
- 中文字体依赖操作系统自带的字体文件，脚本里给了 Windows / macOS / Linux 三套常见路径，都没有就明确报错让你装一个。
  打包给没有中文字体的精简 Linux 服务器时，要把字体文件一起带上并放进候选列表。
- 报告版式是代码画的（无 Word/Excel 模板）。要用单位现成的模板出 PDF，这条路走不通，
  得换 Office 自动化（VSTO/VBA/Python）那条路——先套模板出文件再转 PDF。
- `source/run_log.txt` 里带着运行主机名和 IP，是给排查用的；对外发这份示例前把这几行删掉。

## 排错表

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| PDF 里汉字是方块 / 空白 | 没注册中文字体，或系统里没有候选字体 | 装一个中文字体，或把字体路径加进 `run.py` 顶部的 `FONT_CANDIDATES` |
| 报 `FileNotFoundError: 找不到可用的中文字体文件` | 同上 | 同上 |
| 多出一份 `检验报告_合计.pdf` | 原始 CSV 的表尾行没被过滤 | 检查表尾行的「检测日期」是否被填了值 |
| 第二页没有列头 | `Table` 没设 `repeatRows` | 加 `repeatRows=1` |
| 报告里少了几个字 / 多个分号 | 单元格文字没转义 | 进 `Paragraph` 前 `escape()` |
| 报错说文件名不合法 | 样品编号里有 `\ / : * ? " < > |` | 用 `re.sub` 换掉 |
| 跑完窗口一闪就没了 | 双击运行的窗口在结束后关闭 | 直接跑 `python run.py`，或看 `source/run_log.txt` |

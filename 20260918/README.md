# 示例：样本流转交接记录串成台账（断链、倒挂、重复、超时一次挑出来）

一管样本从中心发到实验室，要经过接收登记 → 前处理分装 → 检测上机 → 留存入库，
每经一手签一次交接单。单子一张张签的时候看着都对，攒到月底想查"00103V1A 现在在谁手里、
中间有没有断过"，只能把单子摊一桌子一张张对。

这个示例把三份东西拼成一份**流转台账**：

```
样本主表（一行一管样本）
+ 交接记录（一行一次交接：谁交给谁、什么时候）
+ 流转环节规则（一行一个环节：接收岗位、停留时限小时）
→ 02_output/样本流转台账.xlsx 三个页签：流转台账 / 环节停留 / 异常与提醒
```

脚本**只核账、只列问题，不替人改记录**：缺哪一环、哪一段时间倒挂、哪一环记了两条、
哪一环压超了时限，全部列出来交给人去核。

## 怎么跑

```bash
python run.py
```

Windows 上也可以直接双击 `run.py`（跑完会停住等回车，不会一闪而过）。
不想暂停就用 `python run.py --no-pause`。

脚本会自己切到所在目录、缺 `openpyxl` 时自动用清华源装、跑完自动回读校验并打印 `PASS/FAIL`。

## 数据是怎么来的

| 文件 | 实际场景里的来源 |
| --- | --- |
| `01_raw_data/样本主表.csv` | 项目上登记的样本清单：一管一行，带编号、中心、访视点、采集日期 |
| `01_raw_data/样本交接记录.csv` | 各岗位交接后登记进共享表的记录：一次交接一行，带交出方、接收方、交接人、时间 |
| `source/templates/流转环节规则.csv` | 实验室自己定的环节顺序与停留时限，业务上改这一张 |

为什么不用系统里的交接单？**系统里的交接单是一张张签字单**——一张单子对应一次交接。
跨环节串起来的台账、每一环待了多久、哪管的链是断的，系统不给，得把记录拉出来自己串。

## 故意造的边界值

- **前导零抄丢**：`00102V1A` 在现场被写成 `102V1A`（2 条记录），主表里查无此号；
- **交接时间空着**：00203V2A 交给前处理岗那条没填时间；
- **同一环节两条**：00202V1A 前处理岗 11:00 与 11:40 各一条（现场补签）；
- **时间倒挂**：00201V1A 检测岗 09-16 08:00 早于前处理岗 09-16 15:00；
- **跳过中间环节**：00301V1B 接收岗直接交检测岗，前处理分装整环没有；
- **只有一条记录**：00104V1A 只走完接收登记；
- **一条记录都没有**：00302V1A 只有主表里有；
- **停留超时**：00103V1A 检测岗 96.5 小时（限 72）、00103V1B 前处理岗 47.2 小时（限 24）；
- **表尾合计行与说明行**：两张 CSV 各有一行，靠"编号非空/序号非空"丢掉。

## 实测发现的问题与修法

1. **一条记录都没有的样本，被报成"四个环节全缺失"**——不但多出 4 条噪音异常，真正的信号
   （"这管样本压根没登记过"）也埋掉了。改成一进 `build_chain()` 就单独返回一条「无交接记录」。
2. **只有一环时，"末环节时间"和全程小时自相矛盾**——首末时间填的是同一个时间点，全程小时却是空的，
   看着像脚本算错了。改成链没往下走（`len(stages) <= 1`）时两列都留空，状态写「有断链」，
   比给一个 0 小时强。
3. **倒挂那一段的停留不能拿负数去比时限**——负数一定不超限，等于静默放过去。
   现在倒挂段的停留留空、只报「时间倒挂」，「离开时间」照原样写出来当证据。
4. **游离编号不能静默丢弃**（`102V1A` 这类）：丢了就不知道现场抄错了哪一管；
   也不能并进台账（并错等于串到别人身上），单独列一行让人去核。

## 验证环境与已知限制

- 实测环境：Windows 11 + Python 3.13 + openpyxl 3.1.5；回读校验 17 项全绿，总判定 PASS。
- 环节靠「接收岗位」认，所以规则表里的岗位名要和交接记录里的「接收方」写得一致；
  写了规则表里没有的岗位，那条记录不会进链（本示例数据里没造这种情况）。
- 停留按自然小时算（跨天照算），时限写 0 = 这一环不设限。

## 排错表

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 某管样本在台账里显示「无交接记录」 | 交接记录里没有它的登记 | 先去现场核实是没登记还是还没进流程 |
| 异常页出现「游离记录」 | 交接记录里的编号在主表里查不到 | 多半是手抄丢了前导零，去核编号 |
| 环节缺失报了整环 | 中间环节没登记，或岗位名写得不一致 | 核对规则表的「接收岗位」与记录的「接收方」 |
| 停留小时是空的 | 该环节时间没填，或时间倒挂 | 看同一管在异常页的类型 |
| 超时列没刷红 | 该环时限写的是 0（不设限） | 要设时限就改 `source/templates/流转环节规则.csv` |

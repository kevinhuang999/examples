# 示例：送检样品登记与编号自动生成

收样室当天的一堆送样单读进来，逐件编出唯一编号，生成**样品登记台账**（xlsx）+ **待打印标签清单**（csv）；
资料不全、编号编不出来的行一律挂起，一个都不许硬编。

一句话：编号本身不难，难的是**编号必须唯一且连续，而送样单经常带着缺项来**。
手工编是先编号后判定——编到一半发现客户没建代码，号已经写下去了，只能跳号；
脚本是先判定后编号——编不出号的整行不进号段，号段天然是连的。

## 目录结构

```

│   └── 样品类别代码表.csv     ← 样品类别 → 类别码

│   ├── 样品登记台账.xlsx      ← Sheet1 台账 + Sheet2 挂起清单

└── source/
```

**你要碰的就三样**：`01_raw_data/` 里的表（换成自己机构的）、`source/templates/` 里的模板、`run.py` 顶部配置区。

## 怎么跑

```bash
python run.py              # 跑完停住等回车（Windows 双击也行）
python run.py --no-pause   # 跑完直接退出
```

缺 `openpyxl` 会自动用清华源装；装不上手敲一条：

```bash
pip install openpyxl -i https://pypi.tuna.tsinghua.edu.cn/simple
```

想重置数据：`python source/build_fixtures.py`

## 编号规则（要改就改 `run.py` 顶部常量）

```
样品编号 = 受理日期(6 位) + 客户代码(2 位) + 类别码(1 位) + 流水(3 位)
例：260926QHA001   →  2026-09-26 / 客户 QH / 类别 A / 第 001 份
```

- 流水**按「受理日期 + 客户代码 + 类别码」分段**，段内从 001 起连续排。
- **同一客户同一天来第二批（另一张送样单），继续顺着排，不重开 001**。这是最容易出重号的地方：
  收样员看着手上这张单从 001 开始编，下午那张单又从头编一遍。
- 一行送样单 = 一份样品 = 一个主编号；这份样品有几件，编号后加 `-1`…`-N`。
  **件数为 1 不加后缀**——满台账都是 `-1` 没人这么干；件序号不补零，跟规范里的 `-1` 写法一致。
- 挂起的行**不占流水号**。

## 数据故意造了哪些边界

| 造的情形 | 想抓什么 |
| --- | --- |
| 客户名「浙江宏远纺织有限公司」尾巴粘一个全角空格 | 手工看是同一家，字符串比较是两家 |
| 客户样品编号 `0000713` | 一转 int 前导零就没了，标签和原始记录对不上 |
| 受理日期写「待定」 | 认不出日期 → 编号里定不下日期段，整行挂起；**不许兜今天** |
| 客户名整列为空 | 认不出是哪家 |
| 新客户「无锡华信水务」没建代码 | 编不出客户代码段，挂起 |
| 样品类别写「其他」 | 类别码表里没有，**不猜**，挂起 |
| 样品名称空 | 台账上没法标识 |
| 数量写「2 支」 | 正则抠出 2 等于替客户改口径 → 挂起 |
| 同一委托单里 `MD-A-773` 出现两次 | 追溯会串，**两行都挂**，不能只挂后一条 |
| 一行 120 件的大批量委托 | 件序号展开到 `-120`；`-10` 按字符串排会跑到 `-2` 前面 |
| 表尾合计行 + 说明行 | 判空的「受理日期」列留空才能跳过；合计数字写进那一列就多出一条假样品 |

## 造数据 / 写代码时实测发现的问题

1. **`read_csv_rows()` 不能把判空列写死。** 第一版固定用「受理日期」判空，
   结果读「客户代码表」时那张表根本没有这一列 → 每行都被跳过 → 客户代码表读成空，
   **16 行数据全被挂起、台账 0 件**。改法：判空列当参数传（读对照表就传它自己的键列）。
2. **一行 120 件的委托，编号排序不能按字符串。** 台账顺序按 `(送样单行序, 件序号)` 数值排；
   按编号字符串排会把 `-10`、`-100` 插到 `-2` 前面。回读校验里专门断言了这一点。
3. **台账里新增的行必须逐行画边框。** 模板只准备了一行带边框的空明细行；
   真正的行数按件数创建，创建时如果只写值不画边框，Excel 里看着就是"有值没格子"。
4. **日期格要顺手设 `number_format`。** 写进去是 `date`、格式是 `General` 的话，
   Excel 显示成 `46265` 这种序列号；回读时也要按 `date`/`datetime` 判。
5. **客户样品编号走文本格式（`@`）。** 不设的话 `0000713` 在 Excel 里就是 `713`。
6. **中文 CSV 一律带 BOM（`utf-8-sig`）。** 不带的话 Excel 双击打开是乱码，收样室同事第一个就炸。
7. **规则表和数据要一起想。** 给某行填了「类别＝其他」，就得接受它整行挂起；
   数据改完要重跑一遍，别只看某一项从 FAIL 变 OK 就收工。

## 验证环境与已知限制

- Python 3.13 + openpyxl 3.1，Windows 实跑通过，回读校验 **25/25 PASS**。
- 当前只覆盖「送样单已是汇总 CSV」这一步。送样单是扫描件、纸质、微信群里的文字——那一段不在本示例里，
  属于收样受理环节，落地时先定死"谁把它录成 CSV"。
- 校验器不核对「数量」与实收件数是否相符（那是收样清点的活），也不生成条码图片。

## 排错表

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 台账 0 件、全部挂起 | 客户代码表或类别代码表读成空（判空列写死、或表头名对不上） | 看挂起原因是不是全指向"没有代码"；确认对照表第一列名与代码里一致 |
| 报 `模板里找不到表头栏目` | 模板表头文字改了，或中间多了个空格 | 表头按栏目名反查，改模板就得跟 `HEADER` 常量对齐 |
| 编号出现跳号 | 有行被判挂起，那一段就少了号 | 这是设计如此（挂起不占号）；资料补齐后重跑即补上 |
| 台账日期显示成 46265 | 单元格没设日期格式 | 脚本已设 `yyyy-mm-dd`；手工往模板里写要自己设 |
| 前导零丢了 | 客户样品编号被当数字 | 脚本写文本格式 `@`；自己从 Excel 粘数据时先把列设成文本 |
| 重号 | 同一客户同一天的第二张单重开了 001 | 流水段键必须含「受理日期 + 客户代码 + 类别码」，且全批一起编、不要一张单编一次 |

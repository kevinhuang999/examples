# 示例：第三方检测报告批量用印（盖章 + 台账）

把当天送进用印室的一叠报告读一遍：每份报告按**报告类型**查出该盖哪几枚章，
逐页把章图盖到该盖的位置，最后出一份**按「报告 × 章」登记的盖章台账**。
不够格盖章的（没审签、已作废、原件没到、规则缺失、页数对不上）一份都不出，全部挂起。

## 目录结构

```

│   ├── 印章图/                透明底 PNG，文件名 = 章名（缺一枚 → 用到它的报告挂起）
│   └── 报告原件/              待盖章的 PDF（原件只读不改）
├── 02_output/                跑完的成品（脚本自动生成）
│   ├── 已盖章报告/            已盖章_<报告编号>.pdf
│   └── 盖章台账.xlsx          两个工作表：盖章台账 / 挂起清单
└── source/
    ├── templates/盖章台账模板.xlsx
    ├── build_fixtures.py     重造模板与数据（跑一次全部重建）
    ├── requirements.txt
    └── run_log.txt           运行日志（脚本自动生成）
```

你要碰的是 `01_raw_data/` 这四个：申请单、规则表、印章图、报告原件。

## 怎么跑

```bash
python run.py              # 跑完停住等回车（Windows 上双击 run.py 也行）
python run.py --no-pause   # 跑完直接退出
```

缺 `openpyxl` / `pypdf` 会自动走清华源装。要手动装：

```bash
pip install -r source/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

想推倒重来（重造模板、章图、报告 PDF）：

```bash
python source/build_fixtures.py
```

## 这个示例在讲什么

| 事情 | 在哪 |
| --- | --- |
| 章不是每份都一样，按报告类型查规则 | `read_rules()` + `make_plan()` |
| 三种落位：首页右下 / 末页右下 / 右侧骑缝 | `stamp_xy()` |
| 骑缝章一半放到页面外，按骑缝页序阶梯下移 | `stamp_xy()` + `build_page_map()` |
| 章图得先画成一张覆盖页才能合到原件上 | `build_overlay()` |
| 够不够格盖章，顺序就是业务顺序 | `make_plan()` |
| 台账按「报告 × 章」登记，骑缝记页码区间 | `write_ledger()` |
| 原件只读不改，盖好的另存一份 | `stamp_pdf()` |

## 数据故意造了哪些边界

| 造的东西 | 想验的是什么 |
| --- | --- |
| 报告编号 `0000122`（老系统编号） | 前导零全程不能用 int 走一遍，台账和文件名都得带着 |
| 客户名尾巴一个全角空格（`金鼎检测　`） | `strip()` 不管全角空格，比较键要显式压掉 |
| 一份报告在申请单里出现两次 | 第二次不再盖，登记「重复申请」，不然盖章件会被覆盖一遍 |
| 一份报告只有 1 页，规则要求骑缝从第 2 页起 | 页数不够 → 整份挂起，不许默默只盖首页 |
| 报告类型「年度评估报告」没进规则表 | 没规则不许猜，挂起让人去定规则 |
| 「涉外认证章」的章图故意不放 | 章图缺失 → 挂起，且要指名缺的是哪一枚 |
| 申请单里有一份报告的原件没给 | 原件没到 → 挂起 |
| 审签状态有「审核中」「已作废」 | 用印室只收「已审签」，其余一律不放行 |
| 规则表最后一行的`报告类型`为空 | 表尾说明行要能跳过（判空列挑错会静默读空整表） |
| 页数从 1 页到 6 页都有 | 骑缝章的页码区间和阶梯步长要跟着页数变 |

## 写的时候踩到的、都是真实的

1. **`drawImage` 不传 `mask="auto"`，透明底就没了。** 章图是透明底 PNG，叠页时要把 alpha 带过去；
   少了这个参数，生成的覆盖页里章图没有 `/SMask`（透明掩码），透明的地方会变成实色块，把报告上的字压住。
   本机实测：同一个 PNG，默认写法 `SMask=False`，加上 `mask="auto"` 才 `SMask=True`。
2. **PDF 里合页只认 PageObject，图片得先变成"一页"。** 所以先由 reportlab 按目标页的尺寸画一张只有章的
   覆盖页，再用 `merge_page()` 合过去。覆盖页尺寸必须等于目标页，否则章会被缩放。
3. **`page.merge_page()` 是就地改的。** 同一页合两次就是两遍章（位置不一样就叠花了）。
   本示例每页只在一次循环里合一次，且把该页所有章收在**一张**覆盖页上。
4. **骑缝章不用去裁图。** 把章图 x 放在「页宽 − 半个章宽」，超出去的一半在页面外，
   PDF 只画页面内的部分——天然就是半个章。
5. **骑缝的阶梯要按"骑缝页数"排，不是按整份页数。** 用整份页数算步长，最后几页的章会挤在底部一点。
6. **报告编号全程字符串。** `0000122` 用 `int()` 一转就变 `122`，跟报告封面、台账三处对不上。
   页数、页码反而是整数，别一律当文本处理。
7. **台账行数不是"报告数"，是"报告 × 章"。** 审核来查"这份报告盖了哪几枚章"，按行对得上；
   骑缝章那一行的页码写区间（`2-6`），不是拆成 5 行。
8. **`02_output/已盖章报告/` 重跑先清空。** 不清的话上一版的盖章件会留在目录里，被当成这一版发出去。
9. **模板里空白的明细行没有任何样式时，`openpyxl` 读回来根本不存在——所以台账是动态 `append` 行**，
   不靠"预先画好带边框的空行"。
10. **`Font` 要在每个用到它的函数里各自 import。** 在别的函数里 `from openpyxl.styles import Font` 不算数，
    换个函数就 `NameError`。

## 验证环境与已知限制

- 实测环境：Windows + Python 3.13，`openpyxl 3.1`、`pypdf 6.x`、`reportlab 4.x`、`Pillow 10+`。
  回读校验 **31 项全绿**（`run.py` 跑完自动打印）。
- 报告 PDF 由 `build_fixtures.py` 用 reportlab 现造，中文字体走 reportlab 自带的 `STSong-Light`，
  不依赖系统字体文件，所以 Windows / macOS / Linux 都能跑。
- **只处理不带旋转的报告**：页里有 `/Rotate` 的整份挂起（落位坐标要跟显示方向对齐，脚本不猜）。
- **不是电子签章**：这里是往 PDF 上叠印章图，用于内部流程和打印归档。
  带法律效力的数字签名（CA 证书、时间戳、验签）是另一回事，得用签发系统做。
- 报告如果是扫描件（整页是一张位图），一样能盖；但如果要按关键字定位落章位，需要先做版面解析，本示例不做。

## 排错表

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 章的透明底变成一块实色，压住字 | 合页时 PNG 的 alpha 没带过去 | 确认 `drawImage(..., mask="auto")` 在位 |
| 章的位置整体偏了 | 覆盖页尺寸和原件页尺寸不一致 | 覆盖页按 `page.mediabox.width/height` 现算 |
| 某份报告一直挂起说"章图没有" | `印章图/` 里没有对应文件名的 PNG | 文件名必须与规则表里的「章名」逐字一致 |
| 台账少了几份报告 | 那几份挂在「挂起清单」页签里 | 打开第二个工作表看挂起原因 |
| 报告编号变成了 `122` | 中间被转成整数了 | 编号列全程按字符串走，别 `int()` |
| 骑缝章全挤在页面底部 | 阶梯步长按整份报告页数算了 | 按骑缝页数（末页 − 起始页 + 1）算 |
| 双击窗口一闪就没了 | 跑挂了 | 用命令行跑，或看 `source/run_log.txt` 的最后一段 |

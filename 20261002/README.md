# 示例：按规则表把 Excel 台账批量导出成 PDF

一份 `导出规则.csv` 管一批导出任务：要哪个工作簿、哪张工作表、横版还是纵版、文件名怎么拼、要不要页脚页码。
脚本逐条打开源工作簿（**只读，一行都不写回**），按规则排版成 PDF 放进 `02_output/`，顺手把页数、字节数、
缩放比登记成一本 `导出台账.xlsx`——挂起的也留一行，写清为什么没出。

**它解决的问题**：手工一份份"另存为 PDF"，列多的工作表必然被拦腰切到第二页、跨页后没有表头、
文件名还得按客户/接收方一套套拼。

## 故意造了哪些边界

| 边界 | 在哪 |
| --- | --- |
| 批号前导零（`0000710`，文本格式） | 放行台账 A 列 |
| 文字结论（`未检出`）与空结果混在数值列 | 放行台账 D 列 |
| 数据行数超一页（60 行） | 放行台账 |
| 表尾说明行，第一列留空 | 放行台账第 63 行 |
| 列宽合计远超一页（12 列，缩放到 ~80%） | 试剂消耗台账 |
| 只有表头、一行数据都没有 | 培养基空白页 |
| 纵向合并的「考察点」（跨 2 行） | 第 3 批 A 列 |
| 长文本里带 `&`（Mini-HTML 转义） | 备注说明 |
| 命名规则里带 `/` | 规则表第 5 行 |
| 规则指向不存在的工作表 / 不存在的文件 | 规则表第 6、7 行 |
| 同一张表出两份、文件名撞名 | 规则表第 2、8 行 |

## 跑出来的结果

- 8 条任务 → **5 份 PDF + 3 条挂起**（工作表不存在 / 只有表头 / 文件缺失），
  回读校验 **34 项全绿 PASS**，用时约 0.6 秒。
- 放行台账 2 页：第 2 页有表头、有页脚「第 2 页 / 共 2 页」，首行批号 `0000710` 前导零没丢。
- 试剂消耗台账 12 列缩到一页宽（80%），1 页装完。
- 备注说明的命名规则写成 `{源文件}/{工作表}`，输出文件名里的 `/` 被压成 `-`。
- 同表第二份（改纵向）撞名，自动出成 `..._试剂消耗台账_2.pdf`，两份都留着。

## 造数据/写代码时实测踩到的

1. **`data_only=True` 只对"Excel 存过盘"的工作簿管用**：单元格是公式时它读的是缓存值；
   如果工作簿是别的脚本生成的、从没被 Excel 打开过，公式格读回来就是 `None`。
   本示例的源工作簿全是值、没有公式，所以不受影响——**如果有公式，请先用 Excel 打开并保存一次**。
2. **`merge_cells()` 之后，被合并掉的那些格子 `value` 直接变成 `None`**（不是"重复一遍左上角"）。
   所以纵向合并的「考察点」如果不做下填，跨页后那一格就是空的。示例里的下填逻辑就为这个。
3. **横向合并只在左上角留值**：reportlab 的 `SPAN` 遇到分页会直接报错，所以横向合并区剩下的格子留空，
   宁可少一个格子，也不要整份导出失败。
4. **`Paragraph` 是迷你 HTML**：备注里的 `&` 不转义会被当成实体开头，输出成怪东西。
   所有单元格进 `Paragraph` 前一律 `escape()`。
5. **列宽单位是"字符数"不是点**：`column_dimensions[..].width` 拿到的是字符数，
   要按 `(w * 7 + 5) * 0.75` 换算出点宽，再跟可用宽度比——不换算就一定切列。
6. **页脚「第 X 页 / 共 Y 页」只能两遍法**：先把每页状态攒起来，最后知道总页数了再回填，
   写页脚时还不知道总页数。
7. **重跑先清空 `02_output/`**：不清空的话，上一版多出来的文件会被当成这一版的结果一起发出去。

## 验证环境与已知限制

- 验证：Windows + Python 3.13 + openpyxl 3.1.5 + reportlab + pypdf 6.15，34 项回读全绿。
- 中文字体走系统字体（Windows 用黑体），macOS / Linux 在 `FONT_CANDIDATES` 里列了候选路径；
  一个都找不到时会直接报错并提示补路径，不会静默出一堆方块。
- 图表、图片、条件格式、单元格底纹**不还原**——本脚本是"按表重排"，不是"像素级另存为"。
  要 100% 还原 Excel 的排版，得走 Excel 自身的导出通道（需要装 Office）或 LibreOffice headless。
- 数据源只读：脚本全程不 `save()` 源工作簿，`verify()` 里用 sha256 前后比对来钉这一点。

## 排错

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| PDF 整页方块 | 中文字体没注册成功 | 在 `FONT_CANDIDATES` 里补一个本机存在的中文字体路径 |
| 列被切到下一页 | 列宽没缩放，或纸张方向选错 | 看台账里的「缩放比」，选横向重跑 |
| 挂起「找不到工作表」 | 规则表里的工作表名跟实际不一致（空格、全角） | 复制工作表名，别手打 |
| 挂起「没有数据行」 | 那张表只有表头 | 确认是不是该导出；要出空表就删掉这条规则 |
| 页脚没出现 | 规则表「页码」列写的是「否」 | 改成「是」 |
| 表格跨页后没表头 | `repeatRows` 没设成表头行数 | 检查 `write_pdf()` 里 `repeatRows=head_rows` |
| 第二页开始数据串行 | 某行文字太长被换行 | 检查该列宽度，或把长备注拆列 |

# 示例：色谱峰表批量汇总

仪器软件导出的峰表文件（一次进样一份 txt），批量解析成一张 Excel：
**峰明细**（一个峰一行）+ **样品汇总**（一次进样一行，给目标峰的面积归一含量与判定）+ **挂起清单**。

## 你要碰的只有这些

```
20261003/
├── README.md              ← 先看这个
├── run.py                 ← 一键脚本（不改也能跑）
├── 01_raw_data/           ← 原始数据：仪器导出的峰表文件（一次进样一份）
├── 02_output/             ← 跑完的成品（脚本自动生成，不入库）
└── source/
    ├── templates/
    │   └── 峰归属规则.csv  ← 哪个峰算溶剂峰、哪个是目标峰、谁参与归一
    ├── run_log.txt         ← 运行日志（每次追加，不入库）
    ├── build_fixtures.py   ← 重新生成规则表与数据
    └── requirements.txt
```

日常要改的是两个地方：`run.py` 顶部的**配置区**（路径、列名候选、归一含量接受范围、平行样偏差上限）
和 `source/templates/峰归属规则.csv`（峰归属）。逻辑部分不用动。

## 怎么跑

```bash
python run.py              # 跑完暂停，Windows 上双击也行
python run.py --no-pause   # 不暂停，适合写进批处理
```

缺 `openpyxl` 会自动用清华源装。想重造数据：

```bash
python source/build_fixtures.py
```

## 它到底做了什么

1. **读一份文件＝一次进样**：跳过文件头的仪器信息块，靠「第一列写着『序号』」那行找到峰表起点，
   靠「第一列不是数字」认出「总计」行当终点——不数行数。
2. **剔溶剂峰**：按 `峰归属规则.csv`，峰名带「溶剂 / 系统」的不进归一化分母（留在明细里留痕）。
3. **算归一含量**：`该峰面积 ÷ 有效峰面积合计 × 100`，保留两位。
4. **出三页**：峰明细、样品汇总（含量判定 + 平行样偏差）、挂起清单。

## 数据故意造的边界

| 文件 | 造了什么边界 |
| --- | --- |
| `HPLC-20260618-001.txt` | 常规三峰，目标峰名就叫「主峰」，规则表直接命中 |
| `HPLC-20260618-002.txt` | **GBK 编码** + 中文峰名；峰面积写 `<1000`（低于线性下限）；规则表里没有「磺胺甲噁唑」这个名字，走「按最大峰推定」 |
| `HPLC-20260618-003.txt` | 只有溶剂峰 → 没有可参与归一的峰 → 挂起 |
| `HPLC-20260618-004.txt` | 目标峰面积写 `n.d.` → 不能当 0 → 挂起 |
| `HPLC-20260618-005.txt` / `005R.txt` | 同一编号两次进样，**不能并成一条**（并了面积翻倍）；归一含量差 3.83%，超 2% 提示复测 |
| 样品编号 `0000182` | 前导零，写入时设文本格式，读回仍是字符串 |

## 实测踩到的坑（比代码值得看）

1. **低于线性下限的 `<1000` 不能当 0**：当 0 会把归一化的分母悄悄改小，算出来不报错、含量全偏。
   本例按 1000 的一半记，并在明细里标出「低于线性下限，按半值估」。
2. **`n.d.` 与空值必须挂起，不许兜**：一条兜成 0，整份汇总就少一个峰，肉眼看不出。
3. **仪器已经给了「面积百分比」列也别直接抄**：那是各峰自己四舍五入过的，加起来常常不等于 100，
   而且含不含溶剂峰、含不含低于检出限的峰，各家仪器口径不同。口径要固定，就在自己脚本里重算一遍。
4. **「总计」行不能靠行数减一躲掉**：仪器导出偶尔会多一行说明，或峰表后跟一段系统信息。
   本例用「第一列能不能转成整数」筛，稳。
5. **同一文件里可能有多次进样**：按「样品编号 + 进样次数」归堆，别只按样品名分组，
   否则同名两次进样并成一条、面积翻倍，看着像含量超标。
6. **中文仪器软件导出常是 GBK/ANSI**：`read_text(encoding="utf-8")` 会直接抛 `UnicodeDecodeError`，
   按 `utf-8-sig → gbk → utf-8` 依次试即可。没有任何乱码提示的阶段，读出来就是异常，好排查。
7. **列名各家不一**：有的叫「RT」「Area」，本例按列名候选反查列号，不写死列序，换个仪器的导出也能吃。
8. **溶剂峰删掉就查不出问题了**：明细里留着、标「参与归一＝否」，需要回溯时还找得到。

## 已知限制

- 只解析**文本型峰表**（tab 或多空格分隔）。色谱原始信号（时间-响应两列）不在范围内——那需要重积分。
- 定量方式只做了**面积归一化**。外标/内标法要在 `parse_one()` 里加一列校正因子，取哪个峰当内标，
  一样建议放进规则表。
- 峰名匹配是「包含关键词」，不做模糊匹配：仓库里同时有「杂质A」和「杂质A1」时，
  规则表里把更长的关键词写在前面。
- 没有做峰纯度、分离度这类系统适用性判定。

## 排错表

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 挂起清单全是「找不到峰表表头」 | 这台仪器的峰表第一列不叫「序号」 | 在 `COLS["seq"]` 里加上它的叫法 |
| 挂起清单写着「峰面积是「—」」 | 峰面积列是空的，或占位符不在 `AREA_EMPTY` 里 | 把该占位符补进 `AREA_EMPTY`，别改成 0 |
| 中文峰名读出来是乱码 | 编码候选里少了它的编码 | 把编码名加进 `ENCODINGS` |
| 全部样品都算成「低于下限」 | 溶剂峰没被剔除，稀释了分母 | 检查 `峰归属规则.csv` 的关键词 |
| 同一编号出现两行 | 这是同一样品进了两次样，属正常 | 看「平行样偏差」列，超限已标「建议复测」 |

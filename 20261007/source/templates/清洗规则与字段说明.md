# 清洗规则表怎么读

规则表就在 `run.py` 顶部的 `RULES`，一列一条，动作按数组顺序执行。
清洗只改"写法"，不改"含义"——所以表里没有一个推断性动作。

## 六个动作

| 动作 | 作用范围 | 会写进留痕 |
| --- | --- | --- |
| 去零宽 | 去掉 U+200B / U+200C / U+200D / U+FEFF | 是 |
| 去空白 | 去掉全部空白，含全角空格 U+3000、不间断空格 U+00A0 | 是 |
| 全角转半角 | 只动 U+FF01–U+FF5E 与全角空格 | 是 |
| 别名归一 | 按该列 `映射` 表替换；表里没有的一个字都不动 | 是 |
| 日期归一 | 只做能认出来的格式归一；认不出则整行挂起 | 是 |
| （派生）结果拆两列 | 结果原值 → 结果数值 + 结果状态；单位有则挪到单位列 | 否，原值列保留 |

## 固定四步

1. 配置：`FORMATS`（怎么读文件）+ `RULES`（怎么洗格子）
2. 读文件：编码、表头行、表尾说明行
3. 清洗：逐格过规则 → 留痕；结果列拆数值与状态
4. 输出：清洗后数据 + 清洗记录 + 挂起清单 + 台账

## 结果列的四种状态

| 文档里写的 | 结果（原值） | 结果数值 | 结果状态 |
| --- | --- | --- | --- |
| 98.50 | 98.50 | 98.5 | 数值 |
| <0.01 | <0.01 | 空 | 低于下限 |
| 未检出 / ND | 未检出 | 空 | 文字结论 |
| （空） | （空） | 空 | 空 |

`DECISIONS` 之外的结果文字（如"待检""未测"）不当结论用，整行挂起。
带逗号的结果（如 `3,250`）也挂起——分不清是千分位还是分隔符，不许猜。

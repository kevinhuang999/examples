# 示例：ELN 导出数据整合成一张 Excel 汇总表

ELN（电子实验记录本）按批次分次导出实验记录，各次导出的模板版本不同——字段名、列顺序、
编码都不一样。本示例用一张**外置的字段映射表**把它们的共同字段归并成一张汇总表，
认不出的文件与缺主键的行挂起，**列级映射全部留痕**，方便回溯"这个值是从哪个文件的哪一列来的"。

## 数据故意造了哪些边界

| 边界 | 造在哪 | 想验证什么 |
| --- | --- | --- |
| 前导零实验编号 | `0098`、`0102`… | 读进来不能被转成数字 98 |
| GBK 编码 | `ELN_BR-2026-002.csv` | 编码回退；utf-8 读会抛异常不是乱码 |
| 表头不在第 1 行 | 002 上方压了 3 行导出信息 | 不能写死 `header=0` |
| 列顺序被打乱 | 003 / 004 与前两版都不同 | 必须按列名读，不能按下标读 |
| 全角括号列名 | 映射表里 `投料量（g）` | 列名归一之后才匹得上 |
| 同义不同名 | `物料`/`Material`/`原料` | 别名要能指向同一标准字段 |
| 空值 | 003 的 0104 行投料量、收率 | 原样留空，不填补 |
| 非数值文本 | 003 的 0103 行收率 `未测` | 原样保留，不当 0 |
| 表尾说明行 | 003 末行 | 靠判空列切掉，不进汇总 |
| 缺主键的明细行 | 004 第 3 行无实验编号 | 整行挂起，不许"就近补" |
| 同目录混入无关文件 | `其它_环境记录_20261008.csv` | 认不出要挂起，不许硬凑 |
| 同目录混入说明文件 | `ELN导出说明_20261008.txt` | 非数据后缀直接跳过 |

实测结果：扫 5 个数据文件 → 整合 **8 行** / 留痕 **34 条**（32 映射 + 1 丢弃 + 1 非数值原样）
/ 挂起 **2 条**（1 文件级 + 1 行级），12 项回读断言全绿。

## 造数据 / 写代码时实测发现的问题

1. **映射表里漏写标准字段自己的名字**：设计映射表时给「原料」只配了 `物料|Material|原料名称`，
   忘了把 `原料` 本身写进别名——而最新版模板导出的列名恰恰就是 `原料`，
   于是整份 003 被判「缺必需列」挂起。**别名列表要包含标准字段自己**，这是本轮踩到的唯一硬 bug。
2. **`is_integer()` 归一**：Excel 里温度存的是 `90`（int）而 CSV 里是 `"80"`（str），
   直接 `str()` 会得到 `90` 和 `80`，看着一样但 `90.0` 型的不处理就会变成 `90.0`，
   汇总表里出现两种写法。统一按"浮点但值是整数就写整数"处理。
3. **`pd.to_excel` 之后再回开一次工作簿**：`number_format` 得写进已经生成的文件里，
   所以是先 `to_excel` 再 `load_workbook` 设格式再 `save`，多一次读写换前导零不丢。
4. **判空列不能选会缺值的列**：一开始想用「实验编号」切表尾，结果 004 那行缺主键的明细
   会被当成"数据区结束"，后面全丢。判空列改用「批号」（必需列、允许操作人漏填的概率最低）。

## 验证环境与已知限制

- Python 3.13，pandas 2.x，openpyxl 3.x；Windows 实测通过，代码无平台相关调用。
- 已知限制：`判空列` 的语义是"这一列为空即认为后面是表尾说明"。如果你们 ELN 真的会导出
  **批号为空**的明细行，这一行连同它后面的内容都会被切掉——那就换一个必定有值的列做判空列，
  或者把表尾改成按前缀识别（`本表由…导出`）。
- 封装的表头行数靠"命中已知别名 ≥ 2"判断：如果某个文件只导出了 1 个字段，会被判认不出。
  这是刻意的保守选择——宁可挂起让人看一眼，也不要猜错列。

## 排错表

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 某个文件进了挂起清单，原因"找不到表头" | 该文件的列名映射表里都没有 | 把它的列名补进 `字段映射表.csv` 的对应别名栏 |
| 原因"缺必需列：xxx" | 该版模板没导这一列，或列名拼写不同 | 补别名；确实没导就把该字段从 `REQUIRED` 里去掉 |
| 原因"缺主键 实验编号" | 那一行明细本身没编号 | 回 ELN 补齐再导出；不要在这边猜着补 |
| 留痕里出现「同名字段已在本表出现」 | 同一份导出里有两列映射到同一标准字段 | 检查是不是重复导出了同一列，一般保留第一列 |
| 汇总表里数字左边有绿色小三角 | 该列被设成了文本格式 | 正常——前导零和编号必须按文本存，别改成数值 |
| 汇总行数比预期少 | 表尾说明行之前有整行为空 | 空行会被跳过（`if not any(cells)`），不是丢数据 |

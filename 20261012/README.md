# 示例：试剂效期盘点——台账进、盘点表出，一条命令

实验室里月月重复的那件事：把试剂台账从头翻一遍，逐条看有效期，开封过的还要算「开封日期 + 开封后效期」，挑出已过期、快到期和开了封没记效期的。这个示例把整件事做成一条命令：读台账 CSV → 算实际到期日与剩余天数 → 按阈值表定状态 → 生成带标色的盘点 Excel。

## 目录结构

```
20261012/
├── README.md            ← 本文件，先看这个
├── run.py               ← 主脚本（就跑它）
├── 01_raw_data/         ← 试剂台账（系统导出的样子，表头前压了三行导出信息）
│   └── 试剂台账_系统导出.csv
├── 02_output/           ← 脚本生成的结果（跑完才有）
│   └── 试剂效期盘点.xlsx（盘点明细 / 到期提醒 / 盘点汇总 三张表）
└── source/
    ├── templates/
    │   └── 状态阈值表.csv   ← 已过期/紧急/临期的天数阈值，改阈值改这张表就行
    ├── build_fixtures.py    ← 重新造台账与阈值表
    ├── requirements.txt
    └── run_log.txt          ← 运行日志（追加不覆盖）
```

你要碰的只有两处：换掉 `01_raw_data/试剂台账_系统导出.csv` 里的数据（列名对得上就行，别名见 `run.py` 的 `ALIASES`），以及按自己的管理口径改 `source/templates/状态阈值表.csv`。

## 怎么跑

```
python run.py             # 跑完暂停等回车（Windows 双击也能用）
python run.py --no-pause  # 跑完直接退出
```

缺依赖会自动从清华源装（openpyxl）。想手动装：

```
pip install openpyxl -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 判定规则

- **实际到期日 = min(有效期至, 开封日期 + 开封后效期天数)**。试剂开封后往往只能再用几十天，比瓶身印的效期短得多——只看有效期至，会漏掉「开封了却放了半年」的那批。
- 状态按阈值表**顺序**匹配「剩余天数 ≤ 上限」：已过期（< 0）、紧急（≤ 7 天）、临期（≤ 30 天）、正常。当天到期算「紧急」，不算「已过期」。
- 四种情况**不猜，挂「未判定」**并写明原因：效期空、开了封没记开封效期天数、开封日期晚于有效期至（台账有误）、日期写法认不出。未判定不等于合格，也不等于过期。

## 数据故意造了哪些边界

- 已过期（剩 -10 天）、紧急（剩 3 天）、临期（开封效期生效后剩 20 天）、正常各一档；
- 批号前导零（`000210`、`000321`），输出列按文本存，防 Excel 吃掉前导零；
- 效期为空、开封了没记开封效期天数、开封日期晚于有效期至、日期写成「明年3月底」——四种未判定；
- 普通行铺了 34 条，另有平板培养基（效期只剩 5 天）这类真实容易漏的品类；
- 台账表头前压了三行导出信息，`find_header()` 自适应找表头。

## 实测发现的问题（写代码时踩的）

- 「当天到期」第一版被阈值 `-1/7/30` 划给了已过期——把 `已过期` 的上限设成 `-1`（剩余天数 < 0），剩余 0 天自然落进「紧急」，不用在代码里写 if。
- 开封效期比瓶身效期短的情况才是常态（造数据里那瓶缓冲液瓶身还有 300 天，开封效期只给 60 天）——`min()` 取两个到期日里更近的，方向不能取反。
- 日期写法在系统导出里至少有 `2026-10-12`、`2026/10/12`、`2026.10.12`、`2026年10月12日` 四种，`parse_date()` 逐个试；试不出的**不猜**，挂未判定——猜错一个日期比多一条未判定危害大。

## 验证环境与已知限制

- Windows 11 + Python 3.13 实测 PASS（6 项回读断言全 OK）；macOS / Linux 未实测，脚本只用了标准库 + openpyxl，理论上直接跑。
- 台账列名要能对上 `ALIASES` 里的别名（缺字段会显式报错，不会读空表还一声不吭）。
- 只做效期盘点这一件事：不算消耗速率、不接采购系统、不做效期预警推送——那些是下一步的事。

## 排错表

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 报「台账表头缺字段」 | 列名不在 `ALIASES` 别名表里 | 把你的列名加进 `ALIASES` 对应元组 |
| 全部判成「未判定·日期写法认不出」 | 日期是另一种写法 | 在 `parse_date()` 的格式列表里补一个 |
| 状态分布和预期差一档 | 阈值口径不同 | 改 `source/templates/状态阈值表.csv`，不用动代码 |
| 双击窗口一闪就没 | 依赖装完重启了脚本 | 用 `python run.py` 跑，能留住输出 |

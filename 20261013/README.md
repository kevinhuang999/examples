# 示例：样品编号批量生成与台账管理（Excel）

一条命令，把本批样品按规则系统一编号，编号自动接在历史台账后面，不重号、不丢前导零；
编不了的样品单独列出来，不静默丢掉。

## 目录结构

```
20261013/
├── README.md                  ← 你正在看的这份
├── run.py                     ← 主线：读台账 → 续编编号 → 出 Excel（要碰的是它）
├── 01_raw_data/               ← 原始输入（01 → 02 就是操作顺序）
│   ├── 本批样品清单.csv        ← 本批待编号的样品
│   └── 编号台账_已用编号.csv   ← 历史已用编号（表头前压了两行导出信息）
├── 02_output/                 ← 生成结果（不入库，跑完自己看）
│   └── 样品编号清单.xlsx
└── source/                    ← 其余全部收在这里，内部不再分目录
    ├── templates/
    │   └── 编号规则表.csv      ← 检测类型 → 前缀 + 流水位数（改规则改这张表）
    ├── build_fixtures.py      ← 重造上面两份 CSV 与规则表
    ├── requirements.txt
    └── run_log.txt            ← 每次跑追加一段（不入库）
```

你要碰的只有三样：`01_raw_data/` 里的两份 CSV、`source/templates/编号规则表.csv`，然后跑 `run.py`。

## 怎么跑

```bash
python run.py            # 跑完暂停等回车（Windows 双击 run.py 也行）
python run.py --no-pause # 跑完直接退出，适合放进批处理
```

缺 `openpyxl` 会自动从清华源装；装不上再退 `--user`。手动装：

```bash
pip install -r source/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

想重造一份输入数据（会覆盖 `01_raw_data/` 与规则表）：

```bash
python source/build_fixtures.py
```

没有任何硬编码路径，包整体拷到别的机器、别的目录都能跑，不挑 Python 版本（3.8+ 即可）。

## 编号规则

编号形状 `前缀-年月-流水号`，例如 `WS-202610-0004`。三个部分各自有讲究：

| 部分 | 取值 | 为什么 |
| --- | --- | --- |
| 前缀 | `source/templates/编号规则表.csv` 里按检测类型配 | 新开一种检测类型只是加一行表，不动代码 |
| 年月 | 取该样品自己的送样日期 | 补录上月的样品要回到上月那一段接着编 |
| 流水号 | 同「前缀 + 年月」一组内连续，位数由表里的「流水位数」定 | 位数不够时不截断，编号自然变长并给出提示 |

**同一组才连编**：水质 10 月的号和水质 9 月的号互不影响，各编各的。

## 数据故意造的边界

正常数据跑通不代表对，所以输入里埋了这些：

| 边界 | 数据里长什么样 | 期望行为 |
| --- | --- | --- |
| 丢前导零 | 台账里有 `TR-202610-9`（系统导出被当过数字） | 按 **9** 认，下一号 0011；按字符串比会取到 `9` 再编出 0010，跟台账里已有的 0010 撞号 |
| 历史重号 | `WS-202610-0003` 出现两次 | 报出来进待确认清单，不静默继续 |
| 位数溢出 | 食品接触材料历史已到 998，位数 3 | 编到 1000 仍唯一，编号变长并在终端提示 |
| 补录上月 | 一条样品送样日期是 2026-09-30 | 编回 `WS-202609-0008`，不混进当月 |
| 类型不在规则表 | 「微生物检测」没配前缀 | 挂起，进待确认 |
| 样品名称空 | 名称列空 | 挂起，进待确认 |
| 送样日期认不出 | 写成「待定」 | 挂起，进待确认 |
| 某组只有 1 条 | 土壤检测本批 1 条 | 正常编 1 个号，不报错 |

## 跑出来是什么

`02_output/样品编号清单.xlsx`，四张表：

- **新编号清单**：本批 16 个编号（编号列按文本存，贴标签、导出都不会掉前导零；位数溢出的行标红）
- **编号台账**：12 条历史 + 16 条本批，编号列同样文本格式
- **待确认**：4 条编不了的样品，写清是样品清单第几行、什么问题；历史台账里的重号也列在这里
- **编号汇总**：按「前缀 + 年月」分组计数

终端同时打印每组编号区间、溢出提示，跑完做 11 项回读断言（含把刚存的 Excel 重新打开、
确认编号是按文本存的），全 OK 打 `PASS`。

## 写这个示例时实测踩到的坑

1. **表头不是第一行**：台账导出时表头前压了「编号台账导出 2026-10-12 17:20」这类信息行。
   最初按「非空单元格 ≥ 2」找表头，那行正好也是两格，被当成了表头 → 整张表读错。
   改成**按已知字段名认表头**（至少 2 个单元格命中别名表）才认得住。
2. **流水号不能按字符串比大小**：`"9" > "0010"` 在字符串里成立，取 max 会取到 `9`，
   下一号编成 0010 —— 正好和台账里的 `TR-202610-0010` 撞号。一律 `int()` 之后再比。
3. **内存里对不算对**：编号列不设文本格式，Excel 一打开前导零就掉。
   所以断言里加了「重新打开刚存的 xlsx，确认编号是文本」，这一条最初就是红的。
4. **位数溢出别截断**：`f"{1000:03d}"` 得到 `1000`（四位，不截断），这是对的——
   为了凑三位把 `1000` 截成 `000`，等于把两个样品编成同一个号。

## 验证环境与已知限制

- 实测环境：Windows + Python 3.13，`openpyxl 3.1.x`；Python 3.8+ 与 macOS / Linux 未逐条复测。
- 编号规则只覆盖「一个前缀 + 年月 + 一段流水」这一种形状；同一样品要出多个子编号（如 `-A/-B`）、
  或流水号里要混字母的，需另按 `parse_id()` 的写法扩正则。
- 脚本不做编号的「作废/回收」：作废号要留着占位，删掉回收会被下一次续编重用 —— 作废应在台账里
  标状态，而不是删行。

## 排错表

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 报「找不到表头行」 | 导出文件的字段名不在别名表里 | 在 `run.py` 顶部的 `ALIASES` 里补一个别名，或把列名改成标准名 |
| 报「表头里找不到「编号」列」 | 台账里编号列叫别的名字 | 同上，往 `ALIASES[ID_COL]` 里补 |
| 报「检测类型「X」不在编号规则表里」 | 规则表漏了这种类型 | 在 `source/templates/编号规则表.csv` 加一行 |
| 编号对不上人脑里的预期 | 该样品的送样日期落在别的月份 | 编号按送样日期分段，不是按跑脚本的日期 |
| 打开 Excel 前导零还是没了 | 自己另存或复制时没带格式 | 直接复制「新编号清单」里的整列，别只复制文本到新表 |

## 关于这份代码

用来演示「实验室里那些重复劳动怎么自动化」，正文见配套文章。
示例里的数据都是编的，规则表与字段按自己的台账改就行。

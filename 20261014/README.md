# 示例：检验记录批量电子化（模板复制 + 仪器结果回填 + 完整性核查）

一句话：台账里一行记录 → 复制受控模板生成一页电子检验记录，把仪器导出的结果按批号项号填进去、逐项判定，另出一份核查清单，把缺结果、超限、漏签、断号重号、清单外结果一次点出来。

## 目录结构

```
20261014/
├── README.md                ← 先看这个
├── run.py                   ← 你要跑的；一键脚本
├── 01_raw_data/             ← 模拟仪器导出与台账（原始数据）
│   ├── 检验记录台账.csv          本批要出哪些记录
│   └── 仪器导出_结果明细.csv      仪器工作站导出的结果
├── 02_output/               ← 跑完的成品（脚本自动生成，不入库）
│   ├── 检验记录册.xlsx           一页一份记录
│   └── 记录核查清单.xlsx         四张核查表
└── source/
    ├── templates/
    │   ├── 检项清单.csv           品种 → 该检哪些项、限度、数据来源
    │   └── 检验记录模板.xlsx       受控记录模板（表头信息区 + 明细区 + 签名区）
    ├── build_fixtures.py     重造上面这些模板与数据
    ├── requirements.txt
    └── run_log.txt           运行日志（每次追加，不入库）
```

**你要碰的只有两个**：`01_raw_data/` 里换成你自己的两份 CSV，`source/templates/检项清单.csv` 换成你自己的品种与限度。模板 xlsx 照你的记录表排。

## 怎么跑

```bash
python run.py                # 跑完暂停等回车，Windows 可直接双击
python run.py --no-pause     # 跑完直接退出
```

缺 openpyxl 会自动从清华源装。手动装：

```bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple openpyxl
```

重造示例数据（会把 `01_raw_data/` 和模板覆盖回初始状态）：

```bash
python source/build_fixtures.py
```

## 数据故意造的边界

正常数据跑通不代表对，这些是故意留的：

| 边界 | 造在哪 | 期望行为 |
| --- | --- | --- |
| 记录编号断号 | 台账缺 `QC-202610-0004` | 报进「编号与来源异常」，不静默 |
| 记录编号重号 | `QC-202610-0003` 出现两次 | 报出；两份记录都出页，第二页 sheet 名加 `(2)` |
| 批号前导零被吃 | 台账 `0B1207`／仪器文件 `B1207` | 去前导零归一后配上，同时记一条「写法不一致」 |
| 结果空值 | `0231C` 含量测定有行无值 | 判「缺结果」，不是 0、不是合格 |
| 限号值 | `0231B` 水分 `<0.05` | 与上限 0.5 比大小，判符合，不当缺项 |
| 文字结论 | `B1207` 有关物质「未检出」 | 原样填入，判「见方法」，不进超限统计 |
| 同值重复导出 | `0231C` 溶出度两条 88 | 按一条算，记一条重复 |
| 同批同项不一致 | `0B1210` 释放度 90 / 92 | 按第一条填 + 记一条「发出前必须核」 |
| 清单外项目 | `0231A` 干燥失重 | 报「清单外的仪器结果」，不塞进记录 |
| 整批没匹配上 | `0231F` 三个仪器项全无结果 | 3 项缺结果，而不是静默成空记录 |
| 品种不在检项清单 | `QC-202610-0011` 甲硝唑胶囊 | 整份挂起不出页，写明原因 |
| 漏签 | `0002`/`0005` 缺复核人、`0007` 缺检验人 | 记录一览里标「待处理」 |

## 实测发现的问题与修法

1. **`copy_worksheet` 不带打印区域**：复制的记录页单元格、样式、列宽、页面方向都在，**打印区域丢了**（实测：模板 `print_area` 是 `'模板'!$A$1:$F$16`，复制出来是空）。模板排好的「一页一份记录」全靠它，所以 `copy_sheet()` 复制完按模板再设一遍，`verify()` 里回读断言守着这条。
2. **明细行以检项清单为准，不是以仪器结果为准**：第一版按结果行生成记录，漏做、漏导出的项目整行消失，记录看着是满的、其实是缺的。改成按检项清单逐项找结果，找不到就判「缺结果」。
3. **批号前导零归一是匹配问题、不是展示问题**：仪器导出的文件被 Excel 打开过一遭，`0B1207` 变 `B1207`，不归一那批记录全判缺结果——假报警比漏报更费人。归一的同时把差异记一条出去，不静默当成同一个批号。
4. **人工检查项不能和仪器项混在一个「缺项」里报**：`性状` 这类项本来就是检验员填的，混进去会把该手填的项报成漏检。检项清单里加了「数据来源」一列，人工项留空判「待填」、不进缺项统计。
5. **预置明细行不够时不自动插行**：`insert_rows` 会把下方签名区的格式顶乱，脚本直接报错让你先去模板里加行——模板排一次，比脚本每次去修样式便宜。
6. **`print_area` 回读要看复制后的页**：一开始只在模板上断言，等于没验——问题恰恰出在复制这一步。

## 验证环境与已知限制

- 实测环境：Windows 11 + Python 3.13 + openpyxl（本机 venv），判定 PASS（17 项断言全 OK）。
- 只做 `.xlsx` 记录册；模板必须是 xlsx（.xls 老格式 openpyxl 读不了）。
- 判定口径只覆盖：范围限度、单边限度、限号值（`<`、`>`、`≤`、`≥`）、文字结论。修约规则、平行样与复检取数不在这份脚本里。
- 一个品种的检项不得超过模板预置的明细行数（示例模板 8 行），超了脚本会报错，不会闷头写歪。

## 排错表

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 报「找不到表头行」 | 结果文件表头被改过、或列名用了别名表里没有的写法 | 在 `run.py` 顶部 `ALIASES` 里补一个列名 |
| 报「品种不在检项清单里」 | 检项清单缺这个品种 | 往 `source/templates/检项清单.csv` 加该品种的行 |
| 报「模板只预置了 N 行」 | 检项数量超过模板明细行数 | 在模板里加行（别用 `insert_rows` 补样式） |
| 大批记录判「仪器结果缺失」 | 批号两边写法不一致 | 看「编号与来源异常」里的「批号写法不一致」条目 |
| 记录页打出来跨页 | 打印区域没带上 | 已由 `copy_sheet()` 补；换模板后确认模板本身设了 `print_area` |
| 批号在 Excel 里变成数字 | 值格格式不是文本 | 脚本已把批号格设成 `@`；自建模板也要设 |

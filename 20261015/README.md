# 实验室日报周报自动生成（三张台账 → 日报 + 周报）

跑一遍出两份成品：

| 成品 | 内容 |
| --- | --- |
| `实验室日报.xlsx` | `日报总览`（按天一行：接收、件数、完成、超 TAT、异常、在办、备注）+ `逐日明细`（当天接收/完成/异常逐条列出） |
| `实验室周报.xlsx` | `按周汇总`（ISO 周）+ `本周对上周同期`（等长区间对比）+ `缺报与待核清单` |

## 目录结构

```
20261015/
├── README.md                 ← 本文件
├── run.py                    ← 主脚本（只依赖 openpyxl）
├── 01_raw_data/              ← 输入（跑脚本前先放自己的台账）
│   ├── 样品接收台账.csv        列：接收日期、委托单号、客户、样品编号、样品类型、样品数、状态
│   ├── 检测完成台账.csv        列：完成日期、样品编号、检测项、结论、TAT承诺天数
│   └── 异常台账.csv            列：发生日期、样品编号、异常类型、处理状态
├── 02_output/                ← 输出（脚本自动生成）
│   ├── 实验室日报.xlsx
│   └── 实验室周报.xlsx
└── source/
    ├── build_fixtures.py     ← 重造三份测试数据
    ├── requirements.txt
    └── run_log.txt           ← 运行日志（追加不覆盖）
```

## 怎么跑

```bash
python run.py --no-pause          # 跑完不暂停，直接看结果
python run.py                     # 跑完停在「按回车键结束」，方便看控制台输出
python source/build_fixtures.py   # 数据被别人改了、想重造测试数据
```

- 依赖只有一个：`openpyxl`。缺失时 `run.py` 会自动走清华源安装（`requirements.txt` 里也写了，可手动 `pip install -r source/requirements.txt`）。
- Windows 上双击 `run.py` 也能跑；`.csv` 请用 Excel 另存为「CSV UTF-8」，`run.py` 已按 UTF-8 BOM 读取，不带 BOM 也没关系。
- `run_log.txt` 每段开头会记下运行主机与本机 IP，那是本机标识；发给别人时把这两行删掉，或者只发代码。

## 数据故意造的边界值

示例数据覆盖 2026-10-05 ~ 2026-10-15 共 11 天，特意留了这些坑，脚本要能全对：

| 边界值 | 数据里的样子 | 期望行为 |
| --- | --- | --- |
| 日期四种写法 | `2026/10/05`、`2026-10-12 09:20:31`、`2026年10月8日`、`26.10.13` | 全部归到同一天 |
| 日期认不出 | 空值、`待定` | 不计入任何一天，落到 `缺报与待核清单` |
| 完成日期为空 | 三条 | 算「在办」，不算当天完成 |
| 数量列为空 | 1 条（0B1208 未填样品数） | 不计入件数合计，当天备注「有样品数未填」 |
| 同一样品重复登记 | 0F6601 在接收台账出现两次 | 只算一次，取最早接收日，并落清单 |
| 同样品同检项同一天重复 | 0E5501 含量在 10-09 出现两次 | 只算一次 |
| 同样品同检项不同天 | 0A1025 含量 10-07 与 10-09 各一次 | 都算（是复检，不是重复） |
| 周末空档 | 10-10、10-11 全天无记录 | 日报留行、指标留空、不补 0 |
| 超 TAT | 完成日 − 接收日 > TAT承诺天数 | 共 4 条，含承诺 3 天那条 |
| 样品编号前导零 | `0A1025`、`0B1207` 等 | 全程按文本处理，不出成科学计数法 |

跑完 `run.py` 会回读成品并做 12 项断言，全过打印 `总判定：PASS`。当前示例数据下：接收样品 12 个 / 完成检项 12 条 / 在办 2 条 / 待核 10 条。

## 改数据要注意

- **改列名就等于改代码**：列名写在 `run.py` 顶部常量区（`RECV_DATE`、`DONE_SAMPLE` 之类）。台账加列不影响，改名要跟常量对齐。
- **TAT 口径**：`超 TAT = 完成日 − 接收日 > TAT承诺天数`。接收日取该样品**最早一次**登记日；样品在接收台账里找不到、或承诺天数没填，就判不了，不算超也不算未超。
- **周界**：一律 ISO 周（周一到周日）。周报里「本周对上周同期」会取上周**等长区间**，不是拿半周去对整周。
- **空档日不补 0**：留空才是「没记录」，补 0 会读成「那天没干活」。

## 已知限制

- 只吃 CSV，不直接连数据库或 LIMS 接口；要接系统得自己加一层导出。
- 异常台账只做计数，不做根因分类。
- 不生成图表，只出表格；要图就在 Excel 里插，别在脚本里画。

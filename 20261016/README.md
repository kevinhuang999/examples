# 示例：药企 QC 月报自动生成（检项清单 + 检验结果明细 → 一份月报）

把「品种 → 检项规范」的清单和一份检验结果明细（仪器与检验员录入后导出的 CSV）读进来，
按批号归堆、按规范逐项判定、复检取最后一次结果，最后出一份六个页签的 QC 月报，跑完自动回读校验。

## 目录结构

```
20261016/
├── README.md               ← 你正在看的这份，先看它
├── run.py                  ← 主线：跑一次出 QC月报.xlsx
├── 01_raw_data/
│   └── 检验结果.csv         ← 输入①：结果明细导出（仪器 + 检验员录入）
├── 02_output/              ← 输出（生成的，不入库）
│   └── QC月报.xlsx
└── source/
    ├── templates/
    │   └── 检项清单.csv     ← 输入②：品种 → 检项规范（受控清单的简化版）
    ├── build_fixtures.py   ← 重造上面两份输入（上半建清单，下半造结果）
    ├── requirements.txt
    └── run_log.txt         ← 脚本自动生成（不入库）
```

你要碰的通常只有 `01_raw_data/检验结果.csv` 和 `source/templates/检项清单.csv` 两份 CSV。
要重造数据就跑 `source/build_fixtures.py`。

## 怎么跑

```bash
# 方式一：直接跑
python run.py

# 方式二：Windows 双击 run.py（结束前会暂停等回车，窗口不会一闪就没）

# 方式三：脚本里调用，不暂停
python run.py --no-pause
```

缺 `openpyxl` 会自己装（走清华源），不用先手动 `pip install`。想手动装：

```bash
pip install -r source/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

跑完看两处：屏幕上的 `OK/FAIL` 逐项断言和最后一行 `总判定：PASS`；成品在 `02_output/QC月报.xlsx`。

## 月报里有什么

| 页签 | 内容 |
| --- | --- |
| 批次汇总 | 每个批号一行：检项数、合格 / 不合格 / 待检 / 待核、批次结论 |
| 不合格明细 | 最终判定不合格的项，带结果、单位和判定依据 |
| 复检留痕 | 同一检项出现两次以上的，初检值与最终值并排列出 |
| 品种合格率 | 按品种算合格率，分母只含「有规范、已出结果」的项 |
| 检项完成情况 | 品种 × 检项：本月几批、其中几批出了结果 |
| 待核清单 | 待检、清单外检项、该品种缺规范、不在本月的行 |

## 数据里故意造的坑

正常数据跑通不代表对。这 24 行结果 + 9 条清单里留了九种情况：

1. **上月最后一天**的批号（`AML260630`，3 行）——月报按检验日期切月，不进本月汇总，但要进待核清单。
2. **复检**：`AML260702` 的含量测定初检 88.4（低于下限 90）、复检 93.1 → 最终判定取最后一次，但初检必须留痕。
3. **正好等于上限**：水分 8.0，闭区间判合格。
4. **正好等于下限**：含量 95.0、释放度 70.0，同样判合格。
5. **结果为空**：溶出度、释放度各一条 → 待检，不算不合格、不进合格率分母。
6. **清单外检项**：微生物限度在任何品种的清单里都没有。
7. **该品种缺规范**：布洛芬缓释胶囊的「有关物质」没写进清单（同一检项名在别的品种上有）。
8. **前导零批号**：`007`；检验单号 `0000121` 一类也全是前导零。
9. **单侧限度**：水分只给上限、溶出度只给下限。

## 实测发现的问题与改法

- **`float("")` 会炸**：结果列为空的那些行，不能直接 `float()`。先判空返回 `None`，空值单独走「待检」这一档，顺带把「没检」和「不合格」分开——这是最影响报表结论的一处。
- **`round()` 写进 Excel 的值回读要按 round 后比**：合格率 `round(6/7, 3)` 与真值差 5e-4 量级，用 `1e-9` 容差去比真值必挂，得比 `round(6/7, 3)`。
- **前导零批号**：`007` 按字符串读进来、按字符串写出去，回读仍是 `"007"`。中途任何一次转 int，报表和台账就对不上了。
- **`utf-8-sig` 不是可选项**：导出文件带 BOM，不剥掉的话第一个列名会多一个隐藏字符，取列直接取空。
- **「检项名」不能当唯一键**：阿莫西林含量限度 90~110、布洛芬 93~107，规则必须按「品种 + 检项」两级存，否则两家的限度会互相盖掉。
- **不在本月的行不能直接过滤掉**：先单独收着，汇总成一条待核记录，月底对不上数时能说清是哪几行。

## 验证环境与已知限制

- 验证环境：Windows 11 + Python 3.13（openpyxl 3.1）。Windows / macOS / Linux 同一条命令。
- 脚本不绑任何特定 Python 版本，路径全部按 `__file__` 推导，没有硬编码路径。
- 已知限制：结果是「一条检项一行」的明细格式。若仪器导出的是一份文件里多个批号混排、且表头前有仪器信息行，请先在读取阶段定位表头行再进本流程；本示例不处理这一步。
- `source/run_log.txt` 里每段开头记了运行主机名与本机 IP，方便分辨是哪台机器跑的；打包发给别人前把这几行删掉，或只发代码。日志本身不入库。

## 排错表

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 总判定 FAIL，某条断言红 | 数据被改过，或清单里限度动了 | 看红的那条断言名，它写清了期望值，对回 CSV 改 |
| 待核清单多出「该品种缺规范」 | 结果里出现了清单没维护的「品种 + 检项」 | 在 `source/templates/检项清单.csv` 里补这一行 |
| 合格率看某品种是空的 | 该品种没有一条能判定的项 | 检查清单里这个品种的检项与结果表里的是否同名 |
| 报「No such file」 | 输入 CSV 被挪走或改名 | 保持 `01_raw_data/` 和 `source/templates/` 里的文件名不变 |
| Excel 里批号变成 7 而不是 007 | 用 Excel 打开了 CSV 并保存 | CSV 别用 Excel 存回去；用记事本或代码改 |

# 示例：实验室每日检测日报汇总（一批格式各异的片段 → 一份带格式的日报）

每天下班前，各组把当天出的结果发过来：有理化组的 xlsx、仪器软件直接导的 csv、还有人是补录的旧数据。
表头不在同一行、列名中英混写、同一样品当天复测过两次、昨天没出的还得接着追。
这份示例把「收片段 → 认表头 → 归堆取末次 → 写进模板」四步做成一条命令：
`01_raw_data/` 里放片段，跑完在 `02_output/检测日报.xlsx` 得到三个页签（汇总 / 待出结果 / 按组别统计）。

## 目录结构

```
20261020/
├── README.md                  ← 先看这个
├── run.py                     ← 跑主线（你要碰的）
├── 01_raw_data/               ← 输入：各人交上来的片段（你要碰的）
│   ├── 理化组_20261020.xlsx
│   ├── 微生物组_20261020.xlsx
│   ├── 仪器组_20261020导出.csv
│   ├── 前处理组_20261020.xlsx
│   └── 补录_20261019遗留.xlsx
├── 02_output/                 ← 输出：检测日报.xlsx（跑完才有，不进 git）
└── source/
    ├── templates/
    │   └── 日报模板.xlsx        ← 输入：日报模板（样式改这里，别改代码）
    ├── build_fixtures.py      ← 重造模板与片段
    ├── requirements.txt
    └── run_log.txt            ← 运行日志（不进 git）
```

01 → 02 就是操作顺序：`01_raw_data` 进，`02_output` 出。

## 怎么跑

```bash
python run.py --no-pause
```

Windows 直接双击 `run.py` 也行（结尾会停下来等回车，否则窗口一闪就关）。
缺依赖会自动用清华源装 openpyxl；手动装：

```bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r source/requirements.txt
```

想重造模板和片段：`python source/build_fixtures.py`（它会把 `01_raw_data` 清空重建，并删掉旧的日报）。

## 数据故意造了哪些边界

| 边界 | 造在哪 |
| --- | --- |
| 表头不在第一行 | 理化组压了 1 行标题（表头第 2 行）、前处理组压了 2 行须知（表头第 3 行） |
| 列名不统一 | 样品号 / 样品编号 / Sample ID；检测结果 / 结果 / Result；完成时间 / TestTime |
| xlsx 与 csv 混着来 | 仪器软件导出的那条是 csv，还是 UTF-8 BOM、英文表头 |
| 同一样品复测 | S-0001 的 pH 出了 6.82 与 6.85；S-0002 的水分出了 3.15 与 3.17，而且跨两个文件 |
| 结果没出 | 空字符串（S-0020、S-0005）、破折号 `—`（S-0011） |
| 结果不是纯数字 | `<0.05`、`<10` 这种带符号的报告值，不能被当数字吃掉 |
| 补交昨天的数据 | S-0008（10-19 16:40）、S-0013（10-19 17:20）混在今天的片段里 |
| 编号前导零 | `S-0006` 这类编号写成文本，读回仍是 `S-0006` |
| 无单位 | pH 没有单位，单位列必须允许空 |

## 实测发现的问题与改法

1. **一开始用文件名的日期，结果补交的旧数据全进了今天**
   文件名叫 `补录_20261019遗留.xlsx`，但里面混着今天 15:40 的复测和昨天 17:20 的漏交。
   改成按表里「检测时间」的日期分堆，文件名只用来认组别。
2. **先 `concat` 后去重，复测的旧结果会把新结果盖掉**
   合并顺序取决于文件名的排序，谁在后面谁赢，等于抛硬币。
   改成按 (样品编号, 检测项目) 归堆、比检测时间取最晚那条。
3. **表格模板的格式在写数据后就没了**
   直接 `ws.append()` 写进模板，框线、居中、日期格式全变成默认样式。
   改成在模板里留一行空白的「样式行」，写每行前把它的 font / border / alignment / number_format 抄过来。
4. **`—` 被当成有结果**
   只判空字符串时，破折号占位的那条被算成「已出结果」，写进日报就是一条假数据。
   把 `—`、`-`、`/`、未出、待定 一起算作没出结果。
5. **统计页的合计对不上**
   分母只统计了「已出 + 待出」，补交的非当日数据没算进去，合计少了 2 条。
   统计按三个来源分别累加，合计才和读进来的条数闭环。

## 验证环境与已知限制

- Python 3.13 / openpyxl 3.1，Windows 实跑 PASS（14 项断言全绿）。
- 只处理 `.xlsx` 与 `.csv`；`.xls` 老格式要先另存成 xlsx。
- 一个片段只读第一个工作表（`wb.active`），多页签的片段要自己加循环。
- 「组别」取文件名 `_` 前面那段，命名要统一，否则统计会被拆成两组。

## 排错表

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 报「找不到表头」 | 表头行里没有样品编号/样品号/Sample ID 这类关键字 | 改 `HEADER_KEYS`，或让交数据的人保留编号列 |
| 报「缺列：['time']」 | 这份片段没有时间列，列名也不在别名表里 | 在 `ALIAS["time"]` 里补上它的列名 |
| 日报里前一天的数据不见了 | 不是丢了，是进了「补交非当日」 | 它不该进今天的日报，需要的话另做一张补交清单 |
| 编号变成 `6` 或 `1.2E+11` | 源表里编号是数字格式，前导零在源头就没了 | 从源头把编号列设成文本，生成端救不回来 |
| 结果变成 `0.05` | 源表里把 `<0.05` 写成了数字 0.05 | 结果列必须是文本列，录入时别让 Excel 猜 |

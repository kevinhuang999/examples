# 示例：实验室 Excel 模板版本盘点（一堆散模板 → 版本清单 + 受控模板）

共享盘里同一个检验记录模板躺着七八份：`检验记录模板.xlsx`、`- 副本`、`(最终版)`、`_2024改`、`（旧）`，
还有一份根本没写版本号。谁手上是哪一版、哪份才算现行、`最终版` 到底比 `2025新` 新还是旧，没人说得清。
这个示例的做法：**不算文件名，算结构指纹**——按「可见工作表 + 列名集合」把文件归堆，
组内先比版本号再比修改时间挑出现行版，逐份列出列增删，最后照现行版另存一份干净的受控模板。

## 目录结构

│   ├── 检验记录模板_2024改.xlsx
│   ├── 检验记录模板（旧）.xlsx
│   ├── 检验记录模板_2025新.xlsx
│   ├── 检验记录模板_无版本号.xlsx

你要碰的只有 `01_raw_data/`（换成自己的模板目录）和 `run.py` 顶部的常量。

## 怎么跑

```bash
python run.py            # Windows 也可以直接双击
python run.py --no-pause # 不想看"按回车"提示
```

缺 `openpyxl` 会自动用清华源装，装不上退回 `--user`。手动装：

```bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple openpyxl
```

想重造测试数据（会先清空 `01_raw_data/`）：`python source/build_fixtures.py`。

## 数据里故意造的边界

| 边界 | 造法 | 要验的是 |
| --- | --- | --- |
| 表头不在第一行 | 标题行 + 填写说明行把表头压到第 3 行 | 能不能靠列名找表头，而不是写死 `row=1` |
| 列序被打乱、列名带空格 | `_2024改` 把「样品编号」写成 `" 样品编号 "`、括号用了半角 | 归一化之后还应归进同一组，不能一文件一组 |
| 同一份结构存了多份 | `- 副本` 与基准版逐列一致 | 副本不该被当成一个新版本 |
| 隐藏页 | `_2025新` 挂了隐藏的「填写说明」页 | 隐藏页不进指纹，否则谁改说明都算换版 |
| 无版本号 | 标题行被删，表头直接在第 1 行 | 必须判「待确认」，不能默认当现行 |
| 名字骗人 | `(最终版)` 只有 14 列、版本号 V2.0 | 版本号低于全盘最高时要标出来，别按文件名挑 |
| 修改时间骗人 | `- 副本` 的 mtime 比 V2.2 那份还新 | 版本号优先于修改时间 |
| 不该进盘点的文件 | `台账_2024.xlsx`、`~$` 锁文件、零字节文件、`.xls` | 分别给出跳过原因，坏文件不能带崩整轮 |

## 造数据 / 写代码时实测踩到的坑

1. **`find_header()` 在「结果汇总」页返回 -1**：那一页没有「样品编号」这类列，一页都命中不了两个关键字。
   生成受控模板时按主表的表头行位兜底，别拿 -1 去 `cell(row=0)`，直接 `ValueError` 崩掉。
2. **`V2.10` 会排到 `V2.9` 前面**：版本号按字符串比就是这么坑，得拆成 `(2, 10)` 元组比。
3. **隐藏页会让同一份模板分成两组**：一开始把 `wb.sheetnames` 全算进指纹，`_2025新` 因为多了个隐藏页
   自成一组；改成只算 `sheet_state == "visible"` 的页才对。
4. **零字节文件会让整个扫盘中断**：`load_workbook` 抛 `BadZipFile`，必须在单个文件上包 `try`，
   记账进「跳过清单」继续扫下一个。
5. **`max_row` 判断"有没有示例数据"会误判**：受控模板只写到第 2 行（标题 + 表头），断言用 `ws.max_row == 2`；
   如果模板里有合并单元格或格式残留，`max_row` 会虚高，这时该看实际有值的行。

## 验证环境与已知限制

- Windows 11 + Python 3.13，openpyxl 3.1；macOS / Linux 同一条命令可跑。
- 只读第一个可见工作表算指纹。若你的模板第一页是封面、数据在第二页，把 `probe()` 里的 `visible[0]` 换掉。
- `.xls` 不支持（openpyxl 只认 xlsx/xlsm），跳过清单里会提示先另存。
- 版本号必须写在表头附近（前 10 行内）且形如 `V2.1`，改成「第2版」「2024版」抓不到，会落到「待确认」。
- 受控模板只复制表头与列宽样式，不复制数据验证、条件格式、宏——这些要人工在新模板上补一遍再发布。

## 排错

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 版本清单是空的 | `NAME_KEY` 没命中，文件名里不带「模板」 | 改 `run.py` 顶部 `NAME_KEY` 为你自己的命名特征 |
| 明明是同版式却分了好几组 | 列名有肉眼看不见的差异（全角/半角、多了个换行） | 打开「差异明细」看多出/缺失的列名，按实际列名再归一 |
| 现行版挑错了 | 模板里根本没写版本号，只能退回比修改时间 | 给模板加版本号单元格，这是治本的那一步 |
| 提示 `打不开：File is not a zip file` | 文件是零字节或被 Excel 锁着 | 看「跳过清单」，关掉 Excel 再跑 |
| 中文列名乱码 | Windows 控制台编码不是 UTF-8 | 输出文件本身没问题，用 Excel 打开看即可 |
